## ⛔ Ce lot n'ouvre PAS d'arbitrage — la convention est déjà tranchée (#477)

Les 5 cas `withDefaults` ressemblent à un choix entre deux corrections :
renommer la prop (`placeholder` → `placeholderKey`, **cassant**), ou garder le
nom et résoudre par `t()`.

Ce choix a déjà été rendu dans ce dépôt, et l'interface de `ChartCartesian`
l'écrit noir sur blanc :

> *« Carries a locale key, not final text — it is resolved through the DS `t()`
> mechanism. Defaults to `'origam.chart.zoom.reset_aria_label'` (#477). A raw
> string that matches no key is returned unchanged, so
> `zoomResetLabel="Reset the view"` still works for consumers who prefer to
> translate on their side. »*

Le mécanisme est vérifié dans `utils/Commons/locale.util.ts` l.225-227 :

```ts
// Cle absente : on rend la cle, jamais une chaine vide — c'est ce qui
// rend un trou de traduction visible plutot que silencieux.
if (template === undefined) return key
```

**La prop garde son nom, sa valeur par défaut devient la clé, et le texte brut
d'un consommateur continue de traverser inchangé.** Aucune rupture d'API, donc
aucune question à poser : on exécute.

## Portée de la correction

Un défaut C8 est un **bug produit**, pas un trou de couverture (contrairement à
C5). Il se voit à l'écran dès que la locale n'est pas l'anglais. Les 11
occurrences se corrigent dans les 9 composants, avec les clés ajoutées à
`en.json` **et** `fr.json` dans le même commit, et story + doc synchronisées.
