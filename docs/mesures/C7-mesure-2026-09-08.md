## Deux corrections du détecteur avant ce versement

La première mesure donnait 54/162. Deux familles de **faux rouges** ont été
trouvées en relisant les verdicts sur pièce — un faux rouge coûte autant qu'un
faux vert, puisqu'il envoie corriger ce qui va bien.

### A — contrôles aplatis (13 props, 4 composants) — **bug, corrigé**

Le détecteur cherchait littéralement `state.<prop>`. Or les contrôles Histoire
**ne bindent que des primitifs** : une prop de type objet ne peut pas avoir de
contrôle à son nom. La story correcte expose des contrôles aplatis et les
recompose. `OrigamAppBar` le dit dans son propre code :

```
// The `image` prop is an object (`IImgProps`) — Histoire controls only
// bind primitives, so the story exposes flat `imageSrc` / `imageAlt`
:image="resolveImage(state)"
<HstText v-model="state.imageSrc" title="Image Src"/>
```

Chercher `state.image"` y échoue et accuse une story exacte. La forme aplatie
est désormais reconnue sous **deux conditions cumulatives** — la prop est bindée
dans le template ET un `state.<prop><Suffixe>` existe — pour ne pas fabriquer de
vert : un `state.imageSrc` isolé, sans `:image=` en face, pourrait appartenir à
une autre prop.

Composants concernés : `OrigamAppBar`, `OrigamDatePickerHeader`,
`OrigamDatePickerMonth`, `OrigamLayout` (+ `OrigamCalendar`, `OrigamChartTooltip`,
`OrigamConfirmWrapper`, `OrigamDataTableRows`, `OrigamFileField*Item`,
`OrigamTextareaField`, déjà rouges par ailleurs).

### B — fixture statique sans contrôle (84 props) — **arbitrage utilisateur**

84 props sont bindées dans la story à une fixture statique
(`:items="navItems"`, `:code="shortSnippet"`) sans contrôle manipulable.
Partage mesuré :

| | |
|---|---|
| objet / tableau / fonction — contrôle **impossible** | 44 |
| primitif — contrôle **possible**, simplement absent | 40 |

Trois définitions étaient défendables, écartant 22 composants entre les extrêmes :

| définition | conforme / défaut |
|---|---|
| strict — pas de contrôle = défaut | 58 / 158 |
| **objets exemptés** (retenue) | **73 / 143** |
| toute prop bindée = couverte | 80 / 136 |

**Arbitrage rendu par l'utilisateur le 2026-09-08 : exempter les objets et
tableaux seulement.** Motif : compter les 44 en défaut rend le critère
insatisfiable — aucune story ne peut les verdir tant qu'Histoire ne binde que
des primitifs, et un rouge qui ne dit pas quoi corriger est du bruit. Les 40
primitifs restent rouges : `OrigamCode.code: string` n'attend qu'un `HstText`,
`OrigamChip.modelValue: boolean` un `HstCheckbox`. La colonne reste une liste de
tâches faisables.

L'exemption **exige la bindure**. Une prop objet ni bindée ni contrôlée n'est
démontrée nulle part et reste un défaut.
