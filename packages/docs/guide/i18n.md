# Internationalisation

origam traduit ses propres chaînes — libellés ARIA, états vides,
descriptions de graphiques — via un adaptateur i18n injecté par
`createOrigam()`. Aucune chaîne destinée à l'utilisateur n'est écrite en
dur dans un composant.

## Choisir la langue

```ts
import { createOrigam } from 'origam'

app.use(createOrigam({
    locale: {
        locale: 'fr',
        fallbackLocale: 'en'
    }
}))
```

Les messages livrés avec le DS se trouvent dans
`packages/ds/src/assets/locales/` (`en.json` fait foi, `fr.json` suit).
Vos propres messages sont fusionnés par-dessus :

```ts
app.use(createOrigam({
    locale: {
        locale: 'fr',
        messages: {
            fr: {
                origam: {
                    chart: {
                        bullet: { aria_label: 'mon libellé à moi' }
                    }
                }
            }
        }
    }
}))
```

Une clé absente rend **la clé elle-même**, jamais une chaîne vide : un
trou de traduction reste visible plutôt que silencieux.

## Interpolation

Deux formes, au choix :

```json
{ "positionnel": "de {0} à {1}", "nomme": "de {min} à {max}" }
```

```ts
t('positionnel', 3, 9)              // « de 3 à 9 »
t('nomme', { min: 3, max: 9 })      // « de 3 à 9 »
```

Une valeur non primitive (objet, tableau, fonction) rend une chaîne vide
plutôt que `[object Object]`.

## Pluriels

Le pluriel est résolu par **`Intl.PluralRules`**, natif dans Node et dans
tous les navigateurs cibles. Vous écrivez une clé par **catégorie CLDR**,
suffixée à la clé de base :

```json
{
  "desc_one":   "Graphique à puce avec {count} indicateur.",
  "desc_other": "Graphique à puce avec {count} indicateurs."
}
```

et vous appelez la **clé de base**, le compte en premier argument :

```ts
t('origam.chart.bullet.desc', 2)   // « … avec 2 indicateurs. »
```

Le compte est exposé sous `{count}` et sous `{0}`.

### Les six catégories

`zero`, `one`, `two`, `few`, `many`, `other` — ce sont celles de CLDR, et
**c'est la locale qui décide desquelles elle a besoin** :

| locale | 0 | 1 | 2 | 3 | 5 |
|---|---|---|---|---|---|
| `en` | other | one | other | other | other |
| `fr` | **one** | one | other | other | other |
| `ru` | many | one | few | few | many |

Notez que le français et l'anglais **ne s'accordent pas sur zéro** : « 0
indicateur » en français, « 0 indicators » en anglais. C'est précisément
ce qu'un `count === 1 ? … : …` écrit dans un composant ne peut pas rendre.

### Repli sur `other`

Si la catégorie sélectionnée n'existe pas dans votre fichier, la
résolution retombe sur `_other`. C'est ce qui permet à `en` et `fr` de ne
livrer que deux formes pendant qu'un traducteur russe en livre trois —
**sans qu'aucun composant ne change** :

```json
{
  "desc_one":   "…",
  "desc_few":   "…",
  "desc_other": "…"
}
```

Ajouter `_few` / `_many` pour votre langue suffit : le code appelant est
déjà correct.

### Phrases à plusieurs variables

Un objet en dernier argument nomme les autres variables, ce qui garde la
phrase lisible pour la personne qui la traduit :

```json
{ "desc_other": "Graphique {type} avec {series} séries et {count} points." }
```

```ts
t('origam.chart.cartesian.desc', points, { type: 'bar', series: 3 })
```

`count` reste réservé et ne peut pas être écrasé par cet objet.

### Ce que l'adaptateur natif ne fait pas

Pas de messages liés, pas de formatage de dates. Si vous en avez besoin,
passez votre propre adaptateur — `createVueI18nAdapter({ i18n, useI18n })`
— et vue-i18n reprend la main sur toute la résolution, pluriels compris.
`vue-i18n` est un peer **optionnel** : le chemin par défaut ne l'importe
jamais.

## Nombres

`n(valeur)` formate un nombre selon la locale active, via
`Intl.NumberFormat` :

```ts
const { n } = useLocale()

n(1234.5)   // « 1 234,5 » en fr, « 1,234.5 » en en
```

## Convention de nommage des clés

Chaque segment est en `snake_case` minuscule
(`origam.chart.box_plot.aria_label`). Ce format est réservé aux clés de
traduction, ce qui permet d'isoler les traductions d'un simple `grep`
sans attraper les identifiants JS (`camelCase`), CSS (`kebab-case`) ou
les constantes (`SCREAMING_SNAKE_CASE`).
